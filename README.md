# Chehour's Medical Center Accounting System

Chehour's Medical Center Accounting System is a comprehensive software solution
designed to streamline the financial management processes. The system offers a
range of features to facilitate accurate record-keeping, billing and reporting for
medical practices. It is built to enhance efficiency, reduce errors, and provide
valuable insights into the financial health of Chehour's medical center.

## Features

- **Per Doctor Accounting**: Manage financial records for each doctor
  individually, allowing for detailed tracking of income and expenses.
- **Weekly and Monthly Reports**: Generate comprehensive financial reports on a
  weekly and monthly basis to monitor performance and make informed decisions.
- **User-Friendly Interface**: Intuitive design that simplifies navigation and
  data entry for users of all technical levels.
- **Secure Data Management**: Ensures that sensitive financial information is
  protected through robust security measures and access controls.
- **Customizable Settings**: Tailor the system to meet the specific needs of the
  medical center, including billing codes, payment methods, and reporting formats.

## Installation

- Clone the repository to your local machine:

  ```bash
  git clone https://github.com/voiceinthedark/Chehour-mc-accounting.git
  ```

- Navigate to the project directory:

  ```bash
  cd Chehour-mc-accounting
  ```

- Install the required dependencies:

  ```bash
  npm install
  ```

- Start the application:

  ```bash
  npm start
  ```

## Usage

- Access the backend through your web browser at `http://localhost:3017`.
- Access the frontend through your web browser at `http://localhost:4177`.
- Use the provided interface to input financial data, generate reports, and manage
  accounts for each doctor.
